Lock your content until the ad blocker is off.

BlockWall is one JavaScript file with no dependencies. It detects ad blockers and covers your page with a message until the visitor turns the blocker off for your site.

How it detects a blocker

No single test catches every blocker, so BlockWall runs two and locks the page if either one fails.

A bait element
It adds a hidden box with class names like ad-banner and adsbox. Browser-extension blockers hide anything with those names, so a box that has no size means a blocker is active.
A bait request
It requests a well-known ad script. DNS and network-level blockers refuse the request, so a failed request means a blocker is active. BlockWall skips this check when the browser is offline or the request times out.
Re-checking
BlockWall checks again when the visitor returns to the tab, when they press the button, and on a timer. The wall comes down by itself once the blocker is off, and goes back up if it is turned on again.

Install

Upload blockwall.js next to your pages. Put the content to lock inside one element and point target at it.

<script src="blockwall.js"></script>
<script>
  AdBlockWall.init({
    target: "#content",
    mode: "blur",
    title: "Please turn off your ad blocker"
  });
</script>

Prefer no extra script block? Use <script src="blockwall.js" data-auto data-target="#content"></script>.
